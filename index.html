🛠️ Quy Tắc Làm Việc Của Nhóm

Để tránh xung đột Git (conflict) và đảm bảo mỗi thành viên có không gian độc lập:

BƯỚC 01
Vào đúng thư mục

Chỉ làm việc trong thư mục mang tên mình tại members/[tên-thành-viên]/.

BƯỚC 02
Tạo file CV riêng

Tạo file index.html, style.css và ảnh trong thư mục của bạn.

BƯỚC 03
Tạo Branch & PR

Tạo nhánh riêng từ main, commit thay đổi và gửi Pull Request để trưởng nhóm duyệt.

BƯỚC 04
Tự động triển khai

Sau khi merge vào nhánh main, GitHub Pages / Cloudflare Pages sẽ tự cập nhật trang web.
