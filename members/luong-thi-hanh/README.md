# 📄 Hồ Sơ Năng Lực (CV) - Lường Hạnh

CV cá nhân chuyên nghiệp chuẩn quốc tế dành cho **Kỹ sư Phần mềm / Full-Stack Web Developer**, được xây dựng bằng **HTML5, CSS3 hiện đại (Vanilla CSS) và JavaScript**.

---

## 🌟 Tính Năng Nổi Bật

1. **Giao Diện Hiện Đại & Sang Trọng:**
   - Hỗ trợ **Chế độ Sáng / Tối (Dark / Light Theme)** với hiệu ứng chuyển đổi mượt mà, lưu trạng thái tự động qua `localStorage`.
   - Phối màu công nghệ cao cấp (Deep Slate, Sky Blue, Cyan, Emerald), font chữ sắc nét `Plus Jakarta Sans` & `JetBrains Mono`.
   - Tương thích 100% trên mọi kích thước màn hình (Desktop, Tablet, Mobile).

2. **Tối Ưu Hóa In Ấn & Xuất PDF Chuẩn A4:**
   - Tích hợp sẵn CSS chuyên dụng `@media print`.
   - Chỉ cần nhấn nút **"Xuất PDF / In CV"** (hoặc `Ctrl + P`), hệ thống tự động ẩn các thanh điều khiển web, chuyển sang nền trắng thanh lịch, chia trang vừa vặn chuẩn kích thước giấy A4 để gửi nhà tuyển dụng.

3. **Tương Tác Nhanh (Quick Actions):**
   - Nút **Sao chép Số điện thoại (`0343 686 332`)** và **Email** kèm thông báo Toast nổi.
   - Bộ lọc dự án thông minh (**Tất cả**, **Full-Stack**, **Frontend**).
   - Nút cuộn nhanh lên đầu trang (Back to top).

## 🚀 Hướng Dẫn Sử Dụng

### Cách 1: Mở Trực Tiếp Bằng Trình Duyệt (Khuyên dùng)
- Nhấp đúp chuột trực tiếp vào file `index.html` trong thư mục `G:\MyCV` để mở bằng Chrome, Edge, Cốc Cốc hoặc Brave.

### Cách 2: Mở Bằng Live Server (Nếu dùng VS Code)
- Mở thư mục `G:\MyCV` trên VS Code.
- Nhấp chuột phải vào `index.html` chọn **Open with Live Server**.

### Cách Xuất File PDF:
1. Nhấp vào nút **"Xuất PDF / In CV"** ở góc phải thanh công cụ (hoặc nhấn phím tắt `Ctrl + P`).
2. Tại mục **Máy in đích (Destination)**, chọn **Lưu dưới dạng PDF (Save as PDF)**.
3. Kích thước trang: **A4**.
4. Tỷ lệ: Mặc định (Default) hoặc Tuỳ chỉnh 95-100% nếu muốn vừa vặn trang nhất.
5. Nhấn **Lưu (Save)**.

## ✏️ Hướng Dẫn Tùy Chỉnh Thông Tin
- **Thay ảnh cá nhân:** Chép ảnh của bạn vào thư mục `assets/` và đặt tên là `avatar.jpg` (hoặc sửa đường dẫn thẻ `<img>` trong `index.html`).
- **Chỉnh sửa kinh nghiệm / dự án:** Mở file `index.html`, các phần được phân chia rõ ràng bằng các comment tiếng Việt như `<!-- HỌC VẤN -->`, `<!-- KINH NGHIỆM LÀM VIỆC -->`, `<!-- DỰ ÁN NỔI BẬT -->`.
